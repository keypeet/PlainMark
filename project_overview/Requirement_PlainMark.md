**สร้างแอป ชื่อ PlainMark**

**Simple Markdown Note Editor: แอปจดบันทึกแบบ Text-first พร้อม Markdown Preview**



**Requirement: แอปจดบันทึกแบบ Text Editor พร้อม Markdown Preview**



**ต้องการพัฒนาแอปสำหรับใช้งานบนคอมพิวเตอร์ โดยสามารถติดตั้งหรือใช้งานผ่าน Git ได้ ตัวแอปมีลักษณะคล้าย Notepad ผสมกับตัว Markdown Preview และมีรูปแบบการใช้งานพื้นฐานคล้ายเอกสารทั่วไป (เสมือนพิมพ์ doc แต่แสดงผลเป็น Markdown Preview)**



**ปัญหาที่ต้องการแก้**



**ปัจจุบันผู้ใช้มักจดบันทึกข้อมูลต่างๆ ด้วยไฟล์ .txt ใน Notepad เพราะใช้งานง่ายและพิมพ์ได้ทันที แต่ในขณะเดียวกันก็ชอบรูปแบบการแสดงผลของ Markdown ที่ดูเป็นระเบียบและสวยงามกว่า เช่น หัวข้อ ตัวหนา ตาราง รูปภาพ โค้ดบล็อก เป็นต้น**



**อย่างไรก็ตาม ผู้ใช้ยังไม่ถนัดการเขียน Markdown syntax โดยตรง เช่น การใส่ ### เพื่อทำ Heading หรือการเขียนโครงสร้าง Markdown อื่นๆ จึงต้องการเครื่องมือที่ช่วยให้เขียนแบบ Text ปกติได้ง่ายขึ้น แต่สามารถแสดงผลออกมาเป็น Markdown Preview ที่สวยงามได้ทันที**



**เป้าหมายหลักของแอป**



**ให้ผู้ใช้สามารถพิมพ์ข้อความแบบธรรมดาเหมือนเขียนไฟล์ .txt แต่ระบบสามารถแสดงผลเป็น Markdown Preview ได้แบบเรียลไทม์ เพื่อให้การจดบันทึกอ่านง่าย สวยงาม และใช้งานสะดวก โดยไม่จำเป็นต้องจำ Markdown syntax ทั้งหมด**



**ฟีเจอร์หลักที่ต้องการ**



**มีหน้าจอสำหรับพิมพ์ข้อความเหมือน Text Editor หรือ Notepad**

**มี Markdown Preview แสดงผลแบบเรียลไทม์ คล้าย Markdown Preview**

**ผู้ใช้สามารถเขียนข้อความธรรมดาได้ตามปกติ และเห็นผลลัพธ์ในรูปแบบ Markdown ที่จัดหน้าสวยงาม**

**มีปุ่มหรือแถบเครื่องมือด้านขวาสำหรับเลือกใส่รูปแบบ Markdown ได้ง่าย เช่น**

* **Heading**
* **Bold**
* **Italic**
* **Table**
* **Fenced Code Block**
* **Inline Code**
* **Image**
* **Link**
* **List**
* **Quote**
* **Horizontal Rule**

**รูปแบบ Markdown ที่รองรับควรอ้างอิงจาก Markdown Guide Cheat Sheet**

**ผู้ใช้สามารถเลือก Export ไฟล์ออกมาได้อย่างน้อย 2 รูปแบบ:**

* **.txt**
* **.md**

**แนวคิดการใช้งาน**



**ผู้ใช้ควรสามารถพิมพ์บันทึกได้แบบง่ายที่สุดเหมือนเขียน Notepad แต่เมื่ออยากจัดรูปแบบ ก็สามารถกดปุ่มด้านข้างเพื่อแทรก Markdown syntax หรือจัดรูปแบบข้อความได้ทันที จากนั้นระบบจะแสดง Preview ให้เห็นผลลัพธ์แบบสวยงาม**



**ผลลัพธ์ที่คาดหวัง**



**ได้แอปจดบันทึกที่ใช้งานง่ายสำหรับคนที่ชอบเขียน .txt แต่ต้องการความสวยงามและความเป็นระเบียบของ Markdown โดยไม่ต้องเรียนรู้ syntax เยอะ ทำให้การเขียนบันทึก เอกสารสั้นๆ โน้ตส่วนตัว หรือคู่มือเล็กๆ ทำได้สะดวกและเร็วขึ้น**
